Why this page exists

Twenty-one of the twenty-two carry a Creative Commons licence that requires a credit. Resizing a JPEG strips the rights metadata that came with it, so the licence survives only as a written record — this one. Each entry links back to the Commons file page, which is the authoritative source for the licence terms.

ShareAlike

Twelve of these are CC BY-SA. ShareAlike attaches to derivatives of the photograph, not to the page that displays it. A cropped copy republished elsewhere carries the same licence; using the image inside this guide does not turn the guide into a derivative work.
